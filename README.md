# ExpiryTrack

Information Systems Senior Project

Organizational lifecycle management system for managing time-sensitive organizational resources such as contracts, licenses, subscriptions, certifications, insurance, policies, and permits.

## Technology Stack

- Frontend: Vue.js + TypeScript
- Backend: ASP.NET Core / C#
- Database: MySQL

## Project Structure
- `backend/` - ASP.NET Core Web API
- `frontend/` - Vue frontend
